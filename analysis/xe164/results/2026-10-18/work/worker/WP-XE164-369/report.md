## Source-derived behavior

`get_read` starts with `CMP r0,#0`; if null, the conditional index load, address add, and value load all skip and `BX LR` returns the original zero. If nonnull, the encoded operations load `I18=[P+0x18]`, form `r0=P+(I18<<2)` modulo 2^32, then load and return the word at `[r0+0x2c]`, i.e. effective address `P+0x2c+4*I18` modulo 2^32. `get_write` has the same path with index word `I1c=[P+0x1c]`. `size` returns zero for null; otherwise it returns `[P+0x28]`. The bodies contain no range or overflow check. The synthetic out-of-range `get_read` case with `P=0x3000`, `I18=7` reaches its source load at `0x3048` and stops because that word is unmapped in the fixture; this is not a claim that arbitrary indices are safe or that a native fault was tested.

`flip` saves `{r4,lr}`, tests `P`, and returns 1 on null without calling either opaque target. On nonnull input, the body calls a direct target at ELF `0x7650`, then uses `r4` as the current object pointer. It loads 64 bits from `P+0x1c`, executes `VREV64.32`, and stores the swapped two 32-bit lanes back to `P+0x1c`; thus `I1c` and `I20` exchange. It stores byte 1 at `P+0x24`, calls the direct target at ELF `0x7a70` with `r0=P`, sets return `r0=0` after normal return, and restores saved `r4`/PC with the actual pop instruction.

`snapshot` likewise saves `{r4,lr}`, returns 1 on null, and calls ELF target `0x7650` for nonnull input. It reads the current byte `[P+0x24]`. If zero, it skips the index reads/writes; if nonzero, it reads `I20` and `I18`, writes byte 0 at `P+0x24`, then writes `I20` to `P+0x18` and `I18` to `P+0x20` (swapping these fields). Both branches then call ELF target `0x7a70` with `r0=P`, set `r0=0` after normal return, and pop the saved frame. The zero-byte branch preserves all three index words. The value 128 is simply a nonzero byte in this source predicate and follows the same conditional swap as 1.

The call targets are computed from the raw ARM branch words: acquire target ELF `0x7650` / Ghidra `0x17650`; unlock target ELF `0x7a70` / Ghidra `0x17a70`. No callee body is included. The exact local postwrite is visible before the unlock BL: flip stores swapped words and byte 1 before `0x12808`; snapshot writes byte 0 and both indices before `0x127c8` on its nonzero path. “Unlock” is only a call-boundary label from the surrounding accepted evidence; this package infers no synchronization behavior from it.

## Explicit fixture conditions and limits

At each mutator entry, the synthetic fixture maps the object bytes used by the body and initializes `P+0x18`, `P+0x1c`, `P+0x20`, and byte `P+0x24`. The pending byte is stipulated; it is not attributed to Root362's create body, which has no explicit store to `+0x24`. Stack words are mapped separately and do not alias the object. At the acquire return boundary, the stepper stipulates normal return, unchanged SP/saved-frame memory, and current `r4=P`, because the next body instructions dereference `r4`; it lets returned `r0` be clobbered to demonstrate that the following source does not use that value. This is a required boundary premise, not a proved ABI property. At unlock, it stipulates normal return with the saved stack frame intact and SP restored to the pre-call frame value. It deliberately clobbers `r0` and `r4`; the source then sets `r0=0` and the pop restores entry `r4`, so no `r4`-preservation assumption is needed across unlock. No source or fixture proves the opaque callees actually meet these conditions.

The three numeric pointer-array accessors only establish their encoded address/load formulas when their selected words are mapped. They do not establish allocation identity, valid index range, bounds, callback meaning, lock semantics, atomicity, or that a runtime object was constructed with the stipulated fields. The finite 36-row transform matrix is instruction-stepped for these selected fixtures; it is not a concurrency model and does not establish general safety. Constructor reachability, runtime binding, actual callback arrays, native execution, API/ABI contract, and physical behavior remain **OFFEN**. Native/runtime/VM/device/network tests are **NOT_RUN**.
