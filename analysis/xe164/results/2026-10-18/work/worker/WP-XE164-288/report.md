# WP-XE164-288 — correction: distinguish the two empty-slot lanes

**Status: VERIFIZIERT** for raw branch destinations and local reachable instructions in the pinned `g_hash_table_lookup` body; **HYPOTHESE/OFFEN** for runtime table states, opaque-call effects, and memory contents. This is a corrective package. Frozen WP283 remains unchanged and its claim that the initial-empty route conditionally consults `r7/r8` is rejected.

The pinned provider is WP280’s exact private FW31 `libglib-2.0.so.0.8200.2` (`3f927b8aae0e3e1b1296bde9009ba9fb9380f64ac26ebe8b7675638e3250cbc5`). WP283 contains 79 contiguous instructions beginning at Ghidra VA `0x55d6c` (ELF VA `0x45d6c`) and three literal words. WP277’s pinned boundary summary supplies only the nested call inputs `r0=table word`, `r1=stack key`; no wider caller or callee is expanded here.

The critical correction is visible directly in the raw instruction word at Ghidra VA `0x55dc4` / ELF VA `0x45dc4`: `0xea000022`. A32 unconditional-branch decoding uses PC+8 and the signed 24-bit displacement shifted by two, yielding target Ghidra VA `0x55e54` / ELF VA `0x45e54`. That target is `mov r0,#0` at `0x55e54`, followed by the saved-register return at `0x55e58`. The branch skips `cmp r7,#0` at `0x55e4c`; the initial-empty route therefore returns zero regardless of current `r7` or `r8`, conditional on reaching this branch and on the stated epilogue/frame conditions. It does not read `r7` or `r8` on this route. The prior WP283 prose and synthetic model that assigned this route the later `r7/r8` behavior were incorrect.

The later probe-empty route is distinct. At Ghidra VA `0x55dfc` / ELF VA `0x45dfc`, `0x0a000012` is BEQ to `0x55e4c`. There, current `r7==0` falls through to the same zero result. Current `r7!=0` branches to `0x55e5c`, uses current `r8<<2` as an offset into the current base in `r2`, and reads a status word at `0x55e60`. Status `<=1` branches to zero at `0x55e54`; status `>1` loads the value at the corresponding current value-array address and returns it at `0x55e74`. Thus only this later lane has the conditional remembered-index dependency. `return-lanes.tsv` records the paths separately, and the validator reconstructs the branch targets from the pinned raw ELF bytes before exercising these lane cases.

Synthetic counterexamples vary `r7` and `r8` independently. For the initial-empty branch, `(r7,r8)=(0,0),(0,17),(1,0),(1,17)` all follow the same direct branch to zero; changing these values cannot activate the `0x55e4c` comparison because it is unreachable from `0x55dc4`. For probe-empty, `r7=0` returns zero without reading `r8`; `r7=1,r8=0` with status 1 returns zero, while `r7=1,r8=17` with status 2 reaches the indexed value load. These are path-condition tests, not binary execution or claims that those memory contents occur.

The address domains are explicit in `address-domains.tsv`. Body/call/literal labels elsewhere in the evidence use Ghidra VA unless marked ELF VA. The two internal BL targets are Ghidra `0xcac64` = ELF `0xbac64` and Ghidra `0x74e64` = ELF `0x64e64`; neither body is expanded. The literal pool is Ghidra `0x55ea8/0x55eac/0x55eb0`, ELF `0x45ea8/0x45eac/0x45eb0`. Their PC-relative derived values are likewise shown in both domains: warning-call `r1` intermediate/final `0xd0ab0/0xd0c5c` (ELF `0xc0ab0/0xc0c5c`), `r2=0xd0a1c` (ELF `0xc0a1c`), and `r0=0xcb600` (ELF `0xbb600`). These are computed addresses, not semantic names.

Opaque callback/direct-call effects, current base-register validity, table layout, callback behavior, and runtime reachability remain open. The body’s 40-byte saved-register frame restores saved registers and SP only if opaque calls return with SP at the expected frame base and do not overwrite the saved frame bytes. No ABI assumption is used. No claims are made from function names alone.
