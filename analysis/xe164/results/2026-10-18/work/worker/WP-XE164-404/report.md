## Path findings

For I=0..3, the source takes the path past the unsigned `I>3` branch, pushes `r4-r6,lr`, reads S0 from G, and sends S0+`0x2c` to the acquire PLT boundary. The body then reloads S1 from G after the opaque event and computes Q=S1+8*I. With `[Q+0x60]==0`, it writes I to `[Q+0x5c]`, writes S1 at `[Q+0x60]`, and forms S1+8*I+`0x5c` as the selected result. A nonzero slot skips those stores and selects zero. Unlock receives S1+`0x2c`; source then copies its current result register to r0 and restores the saved frame. This is conditional on the recorded normal-continuation premises, not an ABI or lock contract.

I=4 and `0xffffffff` take the local out-of-range return before either PLT call. For the requested I=3 map `[S,S+0x74)`, the selector read at `0xe038` attempts the four-byte word `[S+0x78,S+0x7c)` before either owner store; that range is unmapped in the fixture and the model stops there. Extending the explicit map through `[S,S+0x7c)` allows an empty I=3 slot to write owner index 3 and S at the two words, then return S+`0x74`. This does not show a native fault, allocator extent, or bug. The comparison with Init's numeric request `(1,0x74)` is only a conditional size/access-offset comparison if the named call behaves as assumed and Open sees that same allocation.

The acquire-change-global case confirms the model's intended distinction: acquire is called with S0+`0x2c`; the explicit opaque event updates G to S1; source reloads S1 and computes fields from that new value; unlock receives S1+`0x2c`. The memory event chain independently corroborates the stored object words at S1. These are controlled fixture premises, not synchronization semantics or proof that the same object is initialized and used in a real process.

The normal acquire cases require r4 still to hold I, r5 still to designate G, and SP plus saved bytes to remain intact; the body then depends on a readable current G. The normal unlock cases require r4 to retain the selected result and SP/frame plus selected object bytes to remain intact until the source copies r4 and pops.
