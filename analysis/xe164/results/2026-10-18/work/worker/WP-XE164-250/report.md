## Method and evidence

REA was attempted first using its target-free `inspect_binary_layout` operation on the representative hash-bound ELF `8d5a0795ec8eeb45b5f9b997de59d8b972db9c2765cf180e71a7f6fd8de563a5` (`libCmpBlkDrvTcp.so.6.4.6.4`). The exact observed provider error is retained in `rea-layout-gap.json`: provider `pwntools-elf` was unavailable because `REA_PWNTOOLS_PYTHON` had no configured executable path; the provider requested pwntools 4.15.0, pyelftools 0.33, and Unicorn 2.1.2. No installation or alternative REA capability is claimed. Bounded local ELF parsing and GNU ARM objdump were then used.

The validator rechecks each matrix-declared size and SHA before parsing. It reads ELF32 section headers and the exact `ComponentEntry` only from `SHT_DYNSYM`. For the 39 assigned DSOs it selects `SHF_EXECINSTR` sections other than `SHT_NOBITS` and tests 4-byte aligned A32 words. Dal is handled only for header/symbol/section metadata and is excluded before instruction scanning or scan-byte accounting. MOV-immediate hits require a data-processing immediate encoding with opcode MOV, `Rn=0`, `Rd` equal to physical `r0` or `r1`, and the ARM rotated immediate decoding exactly to 15. MOVW hits require the A32 MOVW encoding and a 16-bit immediate of 15. Conditional opcodes and S-bit are retained. Each hit is separately disassembled by GNU ARM objdump using only `[max(section_start,S-16), min(section_end,S+32))`; the window is passed through a transient in-memory file descriptor. The validator does not create temporary on-disk files or mutate its outputs in default mode.

The bounded “first local event” inventory scans only the instructions after each hit within that same window. It records the first recognized direct/conditional or register transfer, PC restore/return-shaped instruction, or write to either `r0` or `r1`; an overwrite of one register does not imply an overwrite of the other. It does not propagate values, follow control flow, or infer call effects. The exact instruction window is not expanded to a containing function. `inputs.tsv` pins the assignment, WP151 report/summary/matrix/hash list, all 40 DSOs, and the GNU objdump executable. The WP151 image-level evidence remains WP151's responsibility.
