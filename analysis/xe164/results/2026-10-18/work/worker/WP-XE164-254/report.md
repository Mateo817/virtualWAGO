## Local pool equations and control

`MemPoolGetBlock` copies entry r0/r1 to r4/r5. Its local guard computes `r3=(entry_r0-1) mod 2^32`, then `CMN r3,#3`; the LS edge is taken for entry r0 in inclusive range `1..0xfffffffe`. The six boundary vectors in `guard-boundaries.tsv` check both endpoints and adjacent out-of-range values. This is a local branch condition, not proof of a global caller/selector path.

On the nonempty-head edge it loads `N=MEM32[M+0x18]`, where `M` is the value in r4, then `next=MEM32[N+0]`; it writes `next` back to `[M+0x18]`. It computes `P=N+0x10`, places `M` in `[N+4]`, and, at the call site `0x17f338`, sets r0=P, r1=0, r2=`MEM32[M+0]`, r3=N. It later places M in r0 for a second opaque call. If those calls return with the relevant saved registers and state intact, the local return expression is r0=P. If the head is zero, the local path calls an opaque target and returns r0=0; on applicable quick-return paths, a nonzero entry r1 receives the literal word `0x14` for no-head/invalid-range cases and word zero for a removed node. These are numeric stores only; no status-code meaning is assigned.

`MemPoolAppendUsedBlock` first rejects entry payload P=0. Otherwise it loads `M=MEM32[P-0x0c]`, computes `N=P-0x10`, and rejects when M=0. The equality `P-0x0c=(P-0x10)+4=N+4` is direct address arithmetic. Thus, if P is the exact `N+0x10` value above and `[N+4]` still holds M, this body reloads that same numeric M value. This does not establish object type, validity, ownership, or persistence.

After an opaque call, the append body reads head from `[M+0x1c]` and clears `[N+0]`. If head is zero it writes N to `[M+0x1c]`. For nonzero head it reads tail from `[M+0x20]`, writes N to `[tail+0]`, reloads `[N+0]`, and writes N to `[M+0x20]` when that reloaded word is zero. The append body returns r0=2 on the two local reject cases and r0=0 after its append paths, conditional on the opaque calls returning and the relevant local memory/register state remaining usable. `cfg-paths.tsv`, `flow-effects.tsv` and `return-conditions.tsv` enumerate the branches and effects separately.
