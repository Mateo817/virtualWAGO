## Row selection and output paths

The pinned static records at indexes 8 and 9 have the same path, type word zero, size word `0xffffffff`, selector word zero and prefix byte zero; their XOR byte at offset `0x20` differs (0 versus 1). The source first loads the row prefix byte at `0x9bdc`; zero takes `BEQ 0x9f24`. The next selector load at `0x9f24` compares with zero; nonzero takes `BNE 0x9fd0`.

For row 8, selector zero falls through to the raw-data path. It loads current `N` from `[SP+0x3c]`; `N=0` branches to `0x9b5c`, before the call. If `N>0`, source loads current handle `F` from `*[SP+0x14]`, current buffer `P` from `[SP+0x38]`, and calls the call target ELF `0x7998` (Ghidra `0x17998`) with `(r0,r1,r2)=(F,P,N)`. The call’s effect or return is not inferred.

For row 9, selector one branches to `0x9fd0`. `r2` still contains the zero prefix byte; the source seeds `[SP+0xd8]` with it before checking `N`. When `N=0`, it skips the loop and later calls with a one-byte zero scratch value. When `N>0`, `P-1` is prepared in `r2`, `P+N-1` in `r0`, and `r3` receives the zero prefix seed. `LDRB r1,[r2,#1]!` increments before reading, so the sequence reads `P` through `P+N-1`. `CMP r2,r0` sets the loop flags; the following `EOR` and `STRB` have S clear and leave those flags intact for `BNE`. With `P>=1`, `N>0`, `P+N-1<=0xffffffff`, writable scratch, and nonoverlapping input/output/frame regions, induction gives exactly N byte reads and the XOR fold. No opaque call occurs on this selected local route before the final call. The final source vector is `(r0,r1,r2)=(F,SP+0xd8,1)` at the same target, ELF `0x7998` / Ghidra `0x17998`.

The exact-file L3 candidate is 16,598 bytes with pinned SHA-256 `26fe2560d12ed794a572186d4f66217a430838f6e1f345f5f6f2f2f0df734abf`; its finite byte fold is `0x83`.
