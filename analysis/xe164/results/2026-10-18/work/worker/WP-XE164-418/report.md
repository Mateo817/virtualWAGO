WP414 is pinned by manifest SHA-256 `b5f66ea90f2c8de0c3687ad87d9dc7e4b6286463b2a8091e16c96c0c8d469e6c` and remains unchanged. The exact artifact copy is FW31 `libpackbus.so.1.0.1`, SHA-256 `3b7b7ca4fa14e5994552040a7b40b1cfbbf43e0649a4ad9277ece421fd4bc5d6`. All 122 selected word rows map to identical raw ELF bytes through a unique PT_LOAD mapping. Four literal words also match. Ghidra-domain addresses in the table translate to ELF addresses by subtracting `0x10000`. Four local bodies are contiguous and call-free in their bounded ranges: no-args `0xeaa4..0xeae8` (18 words), one-arg `0xeaf0..0xeb54` (26), reply `0xeb5c..0xec4c` (61), and last-error `0xec54..0xec70` (8); three associated PLTs contribute nine words. The separate 13 halfwords at `0x1e6c8..0x1e6e0` are table data, not code.

For the two encoder entries, `CLZ(r1)>>5` yields a nonzero invalid marker only when the output pointer position r1 is zero. `CMP r0,#12` followed by `ORRHI` marks unsigned tags greater than 12; the one-arg entry additionally marks a zero r2 argument position using `CMP`/`ORREQ`. The subsequent nonzero test selects the rejection return value 2. The successful no-arg lane stores halfword zero at O+2, then low/high bytes from the selected table halfword at O+0/O+1, and returns zero. The successful one-arg lane stores table bytes at O+0/+1, writes halfword one at O+2, then reads the current halfword through r2 and stores its low/high bytes at O+4/+5. The code order confirms the alias consequence: if r2 is O+2, the load observes the just-written value one. These are local register/address facts; they do not define an external request structure.

The reply body’s first R-relative operation is the halfword read at R+2, followed by R+4; there is no preceding local R null or tag range guard. It stores the low byte of the R+2 value to the PC-derived E+Tag location before converting the status to a low byte and testing it. Nonzero low-byte status selects return 1. If status is zero, low8(R+4) is compared with the full current third register value; mismatch selects return 2. If they match, N=0 or a zero current fourth register skips payload copy with local return zero. R+0 is not checked in this body. The decoded last-error getter is a separate path with an unsigned `tag<=12` branch and returns zero for larger tags; that getter guard is not present in the reply store path.

For the payload path, source words compute `U32(O-R-7)` and compare it unsigned with 14. Only when this quantity is greater than 14 does the conditional compare of `N-1` against 6 select the vector route; because the value used there is the zero-extended `N-1`, that second predicate is equivalent to N>=8 for the already-positive 8-bit N path. The branch-to-scalar condition therefore makes the local vector condition `(U32(O-R-7)>14) and (N>=8)`. This is an address-arithmetic path predicate, not a general overlap-safety rule. The actual VLD1/VST1 words encode Rm=13, and the retained GNU disassembly shows post-index writeback (`[r2]!`, `[lr]!`); each selected pair advances its pointer by 16 bytes while transferring eight halfwords. `N & 0xf8` determines the vectorized prefix `8*floor(N/8)`; the remaining `N mod 8` halfwords use the scalar loop. The bound 1..255 gives at most 510 copied bytes in this arithmetic model, without establishing any real buffer extent.
